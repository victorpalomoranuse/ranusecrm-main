# Guion del vídeo tutorial para diseñadores — RanuseCRM

Dos vídeos cortos (se ven mejor que uno de 40 min). Graba la pantalla con Loom, OBS o la barra de Windows (Win + G), con un proyecto de prueba (por ejemplo `TEST_Gimnasio`). Lee la **voz** tal cual y haz las **acciones** mientras hablas.

---

## VÍDEO 1 — La historia del cliente y Listados (≈ 7 min)

**Idea clave que se explica al principio (0:00–0:30)**
> Voz: "Todo lo que enseñamos al cliente vive en la historia del proyecto. Y el equipamiento y los materiales viven en Listados. Ahora los controlas a la vez: desde cada capítulo eliges qué se enseña, y lo que creas aquí aparece en Listados."

| Tiempo | Acción en pantalla | Voz |
|---|---|---|
| 0:30 | Abrir el proyecto → pestaña **Historia** | "Esta es la historia. Está hecha de capítulos, y cada capítulo de bloques." |
| 1:00 | Mostrar "El punto de partida" (objetivo del cliente) | "Lo primero que ve el cliente es su objetivo, para saber que lo hemos entendido." |
| 1:40 | Abrir un capítulo, añadir bloque de texto | "Añado un bloque de texto: lo que queremos contar de esta zona." |
| 2:30 | Añadir bloque **Render** y subir imagen | "Subo el render. Se ve entero, sin recortar." |
| 3:15 | Añadir bloque **Equipamiento y materiales** | "Aquí está lo nuevo: el equipamiento de este capítulo." |
| 3:45 | Desplegable **Añadir desde Listados…** → elegir máquina → Añadir | "Elijo del listado lo que va en este capítulo." |
| 4:30 | **Crear nuevo en Listados** → nombre, marca, **Subir foto** → Crear | "Si no existe, lo creo aquí mismo; se guarda también en Listados." |
| 5:15 | Flechas ↑ ↓ para ordenar; X para quitar | "Ordeno con las flechas. La X solo lo quita de este capítulo, no lo borra de Listados." |
| 5:50 | Pestaña **Listados** → enseñar que aparece ahí | "Y aquí está. Completo precio, enlace y ficha cuando quiera." |
| 6:20 | Abrir la vista del cliente y descargar el PDF | "Esto es lo que ve el cliente, y el mismo contenido sale en el PDF." |

**Cierre (6:50):** "Regla de oro: se edita todo desde el capítulo; Listados es el almacén."

Notas: los proyectos antiguos que no han elegido nada siguen enseñando todos los equipos con foto, como siempre.

## VÍDEO 2 — Planos (≈ 15 min, dos partes de 7 min)

### Parte A — Dibujar el espacio

| Tiempo | Acción | Voz |
|---|---|---|
| 0:00 | Abrir proyecto → **Planos** | "Planos sustituye a Rayon. Al abrir cada pestaña empieza en Seleccionar." |
| 0:40 | Herramienta **Muros**: dibujar un rectángulo (ángulos de 90° automáticos) | "Dibujo muros. Se pegan a 90°; escribo la medida si quiero exacta." |
| 1:40 | Herramienta **Huecos**: puerta y ventana | "Puertas y ventanas se colocan sobre el muro." |
| 2:30 | Herramienta **Cotas**: clic punto a punto | "Con Cotas mido de punto a punto. Las del muro salen por fuera cuando se puede." |
| 3:30 | Pestañas de estado: **Actual / Distribución / Demoliciones** | "Cada estado es una lámina distinta del mismo plano." |
| 4:30 | **Suelos**: dibujar zona; elegir **Material** y **Acabado/Sistema** (pintura lisa → código **NCS/RAL**) | "Material y acabado son cosas distintas: pintura lisa, y de qué color. Puedes escribir el código NCS." |
| 5:45 | Techos y paredes igual; rodapié en suelos | "Igual con techos y paredes. El rodapié se activa en Suelos." |
| 6:30 | Altura del espacio | "Y la altura del espacio, que sale en las láminas." |

### Parte B — Equipamiento, iluminación y exportar

| Tiempo | Acción | Voz |
|---|---|---|
| 0:00 | Pestaña **Distribución**: insertar bloque/máquina, rotar (cualquier ángulo, 45°) | "Coloco el equipamiento. Se puede rotar a cualquier ángulo." |
| 1:00 | Dibujo propio → clic derecho → **Crear bloque / grupo**; doble clic para editar | "Con clic derecho creo un bloque y lo reutilizo. Doble clic para editarlo." |
| 2:00 | **Iluminación**: puntos de luz y **tiras LED** (modo polilínea, 90°); montaje y perfil | "Elijo montaje y perfil. Cada tipo con su color en la leyenda." |
| 3:15 | **Despieces**: optimizador de material (margen de error) | "El despiece coloca las piezas lo más grandes posible y pide con margen." |
| 4:00 | **Láminas**: elegir las que quieres → numeración automática (A.01, IE.01, I.01…) | "Marco las láminas que salen; la numeración se ajusta sola." |
| 5:00 | **PDF con todas las láminas** y **Vista previa** | "Descargo el PDF o lo reviso antes." |
| 5:45 | **Subir dossier** → elegir láminas → Subir | "El dossier se sube a Documentos del proyecto." |
| 6:20 | **Publicar** una lámina en la historia del cliente | "Y publico una lámina concreta en la historia, con su cajetín y leyenda." |

**Cierre:** "Dentro de Planos hay una pestaña **Tutorial** con 12 lecciones para repasar sin salir de la herramienta."

## Consejos de grabación
- Resolución 1920×1080, zoom del navegador 110–125 %.
- Mueve el ratón despacio; haz una pausa de 1 s antes de cada clic.
- Usa solo datos de prueba (nada de clientes reales).
- Subtítulos automáticos (Loom/YouTube) en español.
